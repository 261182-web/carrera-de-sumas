# 🏁 Carrera de Sumas

Juego educativo de sumas. ¡Llega a la meta primero!

## Cómo jugar
1. Elige modo: **Con un amigo** o **Contra la computadora**
2. Tira el dado 🎲
3. Resuelve la suma
4. Si aciertas, avanzas. Si fallas, te quedas.
5. Meta: casilla **20**

## Instalar como aplicación (PWA)

### En el móvil (Android / iPhone)
1. Abre el enlace en Chrome o Safari
2. Menú → **"Añadir a la pantalla de inicio"** / **"Add to Home Screen"**
3. ¡Listo! Aparecerá como una app con icono.

### En el ordenador (Chrome / Edge)
1. Abre el enlace
2. En la barra de direcciones aparecerá un icono de instalación ➕
3. Haz clic y confirma.

Funciona **sin internet** una vez instalada.
